# Yes Bank Machine Learning Project

## 📌 Project Overview

This project performs exploratory data analysis (EDA) and visualization on historical Yes Bank stock price data. The objective is to understand stock-price behaviour, returns, volatility, relationships between variables, and identify useful insights that can support data-driven financial analysis.

## 🎯 Business Objective

To analyze historical Yes Bank stock data and identify important patterns and trends that can help in understanding price movements, returns, volatility, and potential risk factors.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab
- GitHub

## 📊 Analysis Performed

The project includes:

- Data loading and exploration
- Duplicate-value analysis
- Missing-value analysis
- Variable understanding
- Data cleaning and wrangling
- Feature engineering
- Data visualization
- Year-wise average closing price analysis
- Year-wise volatility analysis
- Monthly return analysis
- Open-to-close price change analysis
- Closing price vs monthly return analysis
- Correlation heatmap
- Pair plot
- Business insights and recommendations

## 📈 Key Insights

The analysis shows significant variation in Yes Bank's historical stock prices and volatility. The stock experienced periods of substantial positive and negative monthly returns, while volatility increased considerably during certain later periods.

Strong relationships were observed among the major stock-price variables such as Open, High, Low and Close. The analysis also highlights periods of increased historical risk that can be investigated further.

## 💡 Business Recommendation

Historical stock-price and volatility information can be used as inputs for a data-driven monitoring and prediction framework. Machine learning models can be developed using price-related and engineered features and evaluated using appropriate performance metrics.

However, historical stock behaviour alone cannot guarantee future market performance, so predictive models should be continuously evaluated and updated with new market data.
